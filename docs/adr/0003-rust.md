# 0003. Rust for engines, bots and tools

- Status: accepted
- Date: 2026-10-06

## Context

CodinGame bots need raw speed, so the candidates were C++ and Rust. Most of the code will be written by Claude and reviewed through tests rather than line by line. A crash on CodinGame is a lost game.

## Decision

Rust for everything: game engines, referees, the arena, tools and bots.

## Consequences

- The compiler rules out whole classes of crashes (memory errors, data races) before CI runs.
- Cargo provides tests, benchmarks, formatting, lints and license checks with no extra setup.
- One engine crate serves the referee, the arena and the bots.
- CodinGame accepts a single file, so a bundler must merge a bot and its crates into one file (Phase 1).
- C++ has more community write-ups for CodinGame; ideas from them are translated, not copied (ADR 0001).
